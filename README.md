# Luca Toniolo — 3D × Code Portfolio

A minimal React/Vite portfolio designed to present 3D work, programming and the intersection between both.

## Run

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Important

The project cards intentionally use CSS-generated placeholder visuals. Replace them with your own renders, screenshots and breakdown images inside `src/assets/` when the projects are ready.

Update social links and contact behavior before publishing.
